Synchronisation multi-appareils

Vos statuts et marquages Folk sont synchronisés via un Gist GitHub privé. Configurez-le une fois sur chaque appareil.

Créez un Gist privé sur gist.github.com avec un fichier cgp-monitor-state.json, puis collez son ID et un token GitHub disposant du scope gist.

Folk CRM

L'envoi vers Folk se fait côté serveur (le navigateur ne peut pas appeler l'API Folk — CORS). La clé est conservée localement.

Marquez les cabinets à pousser via le toggle « Folk » sur chaque fiche, puis cliquez sur Push Folk pour préparer l'envoi (workflow folk-push.yml).
